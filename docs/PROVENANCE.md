# 来源与许可证范围

本公开版本的 Python 管理层、额度桥接、调试协议实现、macOS 原生菜单栏启动器、打包与安装脚本和测试代码为本项目编写。额度条 JavaScript、CSS 与生命周期适配依据功能描述独立实现，延续本项目自己的接口约定和管理代码。

## v0.8.0 的 Sprig 与渲染依赖

芽团 Sprig 的软胶玩具造型、程序化几何、材质配置、灯光、动作控制器和静态 2D fallback 为项目原创。源码分别位于 `web/sprig-source/character.js`、`motion.js` 与 `runtime.js`；没有载入他人的角色模型、纹理或动作文件，也没有把 Spline、Rive 的角色资源纳入发布包。设计参考仅用于理解玩具质感、视线交流和动作预备/回弹/跟随等表现原则。

3D 渲染采用 **Three.js 0.180.0（r180）**，属于第三方代码，不宣称为项目原创。源码包保留其 `web/vendor/three.module.js` 和 `web/vendor/three.core.min.js`，应用包使用包含 Three.js 的本地 `web/sprig.js`。完整上游 MIT 许可保留在 [web/THREE-LICENSE.txt](../web/THREE-LICENSE.txt)，版权归 © 2010-2025 three.js authors；该许可随应用和源码包分发。

`scripts/build-sprig.mjs` 使用锁定的开发依赖 esbuild 0.25.11 从本地模块生成单一 IIFE bundle。`npm ci --ignore-scripts` 安装构建依赖，`node scripts/build-sprig.mjs --check` 重建并比对提交文件。开发依赖不进入应用运行包；运行时无需 Node.js、npm、CDN 或在线模型服务。固定资源清单与 SHA-256 校验用于确认实际注入的是随版本发布的文件，不从外部获取脚本。

运行使用另行安装的 Python 标准库、系统 AppKit/Foundation 框架、macOS 系统工具和官方 Codex 应用及其 CLI。本仓库不分发这些运行时或应用，也不包含 Tk、websocket-client、CoPets 或其他参考项目的实现。协议名称和应用 DOM 选择器用于互操作。

## 数据边界

公开源码和发布包不包含登录资料、认证文件、聊天内容、真实账户额度记录、含账户读数的截图或私人调查材料。测试中的示例身份和令牌均为人工构造的离线数据。新增第三方代码或素材时，应单独核对来源，并保留适用的许可证和通知。

0.7.0 引入的缓存统计是原创的被动元数据适配：依据官方程序中的通知字段与输入区/侧栏标识互操作，仅消费数值。参考了用户提供 Windows 版本的功能语义，没有复制其日志解析器、前端实现或资源；未将朋友源码包纳入公开工程。v0.8.0 保持这一数据边界，角色渲染不读取聊天正文，也不把额度或缓存变化推断成真实工作状态。
