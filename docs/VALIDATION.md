- 在真实浏览器中派发无正文的 `beforeinput`、`input`、`compositionstart`、`compositionend` 合成事件后，同一个横条仍可见且没有重复挂载。
- 移除自身桥接后恢复挂载、断开并重连管理器连接均通过。清理后逐页确认自有桥接和 DOM 均已移除，原日常 Codex 继续运行。
- 视觉检查只截取连接已断开、无真实额度读数的自有横条。图片不随公开源码或包分发。

**验收边界：** 输入文字、发送状态、切换会话和完整页面重载的回归包含合成 DOM/故障夹具；真实窗口检查没有输入或发送测试消息，也没有为了测试导航离开用户当前任务。合成事件不等同实际输入法输入或真实模型生成。没有读取输入正文、聊天历史或会话标识值。

布局不兼容、找不到输入框、多个可见输入框存在歧义、空间不足或发生遮挡时会隐藏横条并重试；不会为保持可见而覆盖原生内容。真实工作事件、当前会话缓存和 Windows 实现仍未接入；缺失的 5h 数据显示未知。动画不表示 GPU 稳定 60 fps。
