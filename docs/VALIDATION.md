## 语言来源与数据边界

- 对本机官方 Codex 程序的静态代码核验确认：应用将提供给 `IntlProvider` 的已解析界面语言同时写入 `document.documentElement.lang`。实机只读检查也确认，页面的 `html.lang` 可以与 `navigator.language` 不同，因此优先使用当前文档语言，文档未提供语言时才回退浏览器语言。不读取或修改用户配置文件，也不从按钮、输入框或聊天正文猜测语言。这属于当前官方实现的互操作依据，不是稳定的公开接口承诺。
- 页面只为语言选择追加标准化 `zh-CN` / `en` 及严格布尔值的焦点、页面可见性元数据。管理器沿用现有约 5 秒心跳，优先选择获得焦点的页面，其次选择可见页面；同级保留已知语言，无有效候选时不重置语言。横条几何可见性与页面可见性分开处理。
- 管理器只在首次选定或语言改变时向原生端发送 `codex-usage-bar-locale:zh-CN` 或 `codex-usage-bar-locale:en`。JavaScript 提取、Python 选择和 Swift 解析均限制这两个值，不把任意页面字符串或原始进程输出显示在菜单中；原有中文状态协议保持兼容。
- 原生启动器尚未获得应用信号时使用系统首选语言：中文语言标记映射为中文，其他语言使用英文。收到有效信号后更新“额度 / Usage”、全部静态菜单及当前状态；已有警告只更新文案，不重新弹出，不改变管理器启停和清理逻辑。
- 语言切换仅更新显示与辅助功能文案，不清除额度或缓存、不重建 Sprig、不改变工作状态。5 小时已用比例、每周剩余比例及缓存匹配规则保持原有语义；缺失数据仍显示未知，真实工作事件仍未接入。
